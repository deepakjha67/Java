# Java for DSA

A curated collection of Java programs focused on the **Collection Framework** and core **Data Structures & Algorithms (DSA)** concepts. This repository serves as a practical reference for understanding Java's powerful utility classes and implementing fundamental algorithms.

## 📚 About This Repository

This project contains sample implementations and demonstrations of Java's Collection Framework, including `HashMap`, `ArrayList`, `Deque`, and `Queue`. It is designed to help learners master Java's standard libraries and apply them to DSA problems.
